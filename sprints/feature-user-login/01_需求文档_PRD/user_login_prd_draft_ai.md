# 用户登录 PRD（AI 初稿）

## 一、功能概述（AI 建议）
提供账号密码登录能力，支持登录态保持、退出登录、失败提示、路由拦截。

## 二、业务规则（AI 建议，需人工确认）
1. 账号：手机号 / 邮箱 / 用户名（**待确认**：以哪个为主？）
2. 密码：**建议** 6-32 位，包含字母 + 数字（**待确认**：是否强制复杂度？）
3. 会话有效期：**建议** 7 天（**待确认**：是否需要短时会话如 2 小时？）
4. 多端登录：**建议**允许共存（**待确认**：是否需要「新登录踢旧」？）
5. 防暴力破解：**建议** 5 次锁 15 分钟（**待确认**：是否需要图形验证码兜底？）
6. 登录成功跳转：回到来源页 / 首页

## 三、权限规则（AI 建议）
- 未登录访问受保护页面 → 302 到 `/login?redirect=xxx`
- 已登录访问 `/login` → **建议**自动跳到首页（**待确认**）

## 四、交互流程（AI 建议）
1. 进入登录页
2. 输入账号、密码，可选「记住我」
3. 点击登录 → loading
4. 成功 → 跳转目标页
5. 失败 → 提示错误（**AI 提醒**：不要区分「账号不存在」和「密码错误」，统一提示「账号或密码不正确」）
6. 顶部导航「退出登录」按钮 → 二次确认 → 清除凭证

## 五、AI 提醒事项
- 🚨 密码禁止明文传输，必须 HTTPS
- 🚨 密码禁止明文存储，必须 bcrypt / argon2
- 🚨 错误提示不能泄露账号是否存在
- 🚨 Cookie 建议 HttpOnly + Secure + SameSite
- 🚨 记得埋点：登录 / 登出 / 失败 事件
