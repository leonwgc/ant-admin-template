# 用户登录 PRD（Official）

> 状态：正式版
> 迭代：feature-user-login

---

## 一、功能概述
已注册用户输入账号 + 密码，校验通过后获得登录态；登录态保持一段时间；支持退出登录；账号密码错误给出提示；未登录访问受保护页面自动跳转到登录页。

## 二、业务规则
1. **账号**：手机号 / 用户名（按现有系统已有的注册字段）
2. **密码**：6-32 位
3. **会话有效期**：7 天免登录；关闭浏览器默认不清除（可勾选「记住我」）
4. **多端登录**：同一账号多处登录允许共存（可选：也可设计成「新登录踢掉旧会话」，由业务决定）
5. **防暴力破解**：连续 5 次密码错误 → 锁定 15 分钟，期间禁止尝试
6. **登录成功跳转**：回到登录前原本想去的页面；无来源则跳转到首页

## 三、权限规则
- **未登录**：仅可访问公开页面；访问受鉴权页面自动重定向至登录页。
- **已登录**：可以访问自己有权限的功能。
- **退出登录**：已登录用户手动点「退出登录」，销毁服务端会话 / 前端 token，回到未登录状态。

## 四、交互流程
1. 用户进入登录页
2. 输入账号、密码；可选勾选「记住我」
3. 点击登录 → 出现 loading
4. **成功**：保存登录凭证，跳转目标页面
5. **失败**：在页面展示对应错误文案（账号不存在 / 密码错误 / 已锁定），**不清空账号输入框，仅清空密码**
6. 导航栏出现「退出登录」按钮；点击确认后注销登录态

## 五、不做（Out-of-Scope）
- 注册
- 找回密码
- 验证码登录
- 微信 / QQ 登录
- 生物识别登录

以上均不在本次迭代范围。
