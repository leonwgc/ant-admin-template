# 上线检查项 — 用户登录

> 迭代：feature-user-login
> 用途：发布前最后一道 checklist，逐项打勾方可上线。

---

## 一、代码与构建
- [ ] 代码已合并到发布分支
- [ ] CI 全绿（lint / build / 测试）
- [ ] 版本号 / changelog 已更新
- [ ] 前端构建产物在正确环境（qa / uat / prod）生成

## 二、配置与密钥
- [ ] 生产环境 `REDIS_URL` 已配置
- [ ] 会话 TTL / 锁定阈值等环境变量已配置
- [ ] JWT / Session 密钥已通过安全渠道注入（**不入代码库**）
- [ ] 生产 `DEBUG` 关闭；不返回堆栈详情
- [ ] 日志级别为 `INFO` 或以上，敏感字段脱敏

## 三、安全
- [ ] HTTPS 证书有效，剩余有效期 > 30 天
- [ ] HSTS 响应头生效
- [ ] Cookie 属性：`HttpOnly`、`Secure`、`SameSite=Lax`（或按业务需要 None）
- [ ] 登录接口限流已开启
- [ ] 错误提示统一为「账号或密码不正确」，不区分账号是否存在
- [ ] 密码字段不出现在任何日志、监控面板中
- [ ] 抓包确认密码密文传输（HTTPS 生效）

## 四、数据库
- [ ] `user_login_session` / `login_failed_record` 表已创建
- [ ] 现有 user 表密码为哈希（bcrypt/argon2），或已明确迁移策略
- [ ] 备份完成，可回滚

## 五、监控与告警
- [ ] 登录成功率监控大盘就绪
- [ ] 登录失败率、锁定率告警阈值配置
- [ ] 5xx / Redis 连接异常告警
- [ ] 埋点日志正常写入（登录成功 / 失败 / 登出）

## 六、功能验证
- [ ] 正确账号密码可登录
- [ ] 错误密码 5 次触发锁定
- [ ] 15 分钟后自动解锁
- [ ] 未登录访问受保护页 → 跳登录页并带 redirect
- [ ] 登录成功后跳回 redirect
- [ ] 退出登录后旧凭证失效
- [ ] 刷新页面登录态保留（记住我）
- [ ] 401 全局拦截生效

## 七、发布通知
- [ ] 通知客服 / 运营 / QA 上线时间
- [ ] 值班同学在岗，联系方式确认
- [ ] 回滚方案已同步团队
