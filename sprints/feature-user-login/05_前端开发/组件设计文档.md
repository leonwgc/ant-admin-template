## 二、登录页 Login.tsx

### Props
无 props；组件通过 hooks 读取路由 & store。

### 表单字段
- `account`：账号（手机号 / 用户名）
- `password`：密码
- `remember`：记住我（`Checkbox`）

### 交互
- 提交时按钮 disable + loading
- 成功：更新 store，跳转 `redirect` 参数指向的页面，无则跳 `defaultRoute`
- 失败：
  - `40001` → 展示「账号或密码不正确」
  - `40002` → 展示「账号已被锁定，请 15 分钟后重试」
  - 网络异常 → 展示「网络异常，请稍后重试」
  - **仅清空密码**，保留账号

### 依赖组件（Neat Design）
- `Form`, `Input`, `Input.Password`, `Checkbox`, `Button`, `Alert`, `message`

## 四、路由守卫 RouteGuard

**在现有 RouteGuard 基础上追加**：
```tsx
const user = useAppStore((s) => s.user);

if (!user) {
  const redirect = encodeURIComponent(location.pathname + location.search);
  return <Navigate to={`/login?redirect=${redirect}`} replace />;
}
```
- 现有的操作权限（`operations`）判断保留在登录态之后
- `/login`、`/no-permission`、`/404` 应加入 `PUBLIC_ROUTES` 白名单

## 五、axios 拦截器 (`src/req.ts`)

**响应拦截追加 401 处理**：
```ts
res => res,
err => {
  if (err.response?.status === 401) {
    useAppStore.getState().clearUser();
    const redirect = encodeURIComponent(location.hash.replace('#', ''));
    location.hash = `/login?redirect=${redirect}`;
  }
  return Promise.reject(err);
}
```

**请求拦截**：如果使用 Cookie Session 则无需手动加 header；若使用 JWT，则从 store 取 token → `Authorization: Bearer xxx`。

## 六、Store 扩展 (`src/store.ts`)

在 `useAppStore` 中新增：
```ts
interface AppState {
  // ... existing
  user: UserInfo | null;
  token: string | null;  // JWT 方案才需要
  setUser: (u: UserInfo | null) => void;
  clearUser: () => void;
}
```
- `setUser` / `clearUser` 同步更新 `operations`（角色 → 操作权限）
- 支持 `localStorage` 持久化（仅 user 基础信息，**不存密码**）

## 七、Service 层 (`src/services/auth.ts`)

```ts
export const login = (params: LoginParams) =>
  req.post<LoginResp>('/api/auth/login', params);

export const logout = () => req.post('/api/auth/logout');

export const getMe = () => req.get<UserInfo>('/api/auth/me');
```
