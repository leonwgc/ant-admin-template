# 后端接口文档 — 用户登录

> 迭代：feature-user-login

---

## 1. 登录

**接口**：`POST /api/auth/login`

**请求体**：
```json
{
  "account": "string, 手机号或用户名",
  "password": "string, 6-32 位",
  "remember": "boolean, 是否记住我"
}
```

**返回**：
```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "token": "string, 或 sessionId",
    "user_info": {
      "id": "number",
      "name": "string",
      "avatar": "string",
      "roles": ["string"]
    }
  }
}
```

**错误码**：
| code | msg | 说明 |
| --- | --- | --- |
| 40001 | 账号或密码不正确 | 账号不存在或密码错误（**统一提示**，不区分） |
| 40002 | 账号已被锁定，请 15 分钟后重试 | 触发暴力破解锁定 |
| 40003 | 参数格式错误 | 账号 / 密码格式校验失败 |
| 50000 | 服务器异常 | 未知异常 |

---

## 2. 登出

**接口**：`POST /api/auth/logout`
**鉴权**：需要（携带 token / session cookie）

**返回**：
```json
{ "code": 0, "msg": "success" }
```

**行为**：销毁服务端会话，清除 Redis session 或加入 JWT 黑名单。

---

## 3. 获取当前用户

**接口**：`GET /api/auth/me`
**鉴权**：需要

**返回**：
```json
{
  "code": 0,
  "data": {
    "id": "number",
    "name": "string",
    "avatar": "string",
    "roles": ["string"]
  }
}
```

用途：前端刷新页面后恢复登录态、获取权限点。

---

## 4. 鉴权中间件约定

- 所有受保护接口经过统一中间件拦截
- 无 token / token 无效 / token 过期 → 统一返回 `401`
- 前端见 `401` 统一跳登录页
- 响应头可选 `X-Redirect-To: /login` 便于前端路由
