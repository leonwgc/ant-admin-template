# feature-user-login

> 迭代名：**用户登录 (user-login)**
> 迭代目标：让已注册用户可以验证身份进入系统，建立统一鉴权与会话规范。

---

## 🔹 业务目的
让已有注册用户可以验证身份进入系统；区分登录 / 未登录状态，保护需要鉴权的功能（例如后续的头像上传、订单等）。

## 🔹 技术目的
建立统一身份认证、会话管理、错误提示规范；沉淀登录相关安全方案（防暴力破解、密码传输、token 管理），后续所有需要登录的功能复用这套鉴权。

## 🔹 本次不做（Out-of-Scope）
- 注册
- 忘记密码 / 找回密码
- 短信验证码登录
- 第三方登录（微信 / QQ / Apple / Google）
- 生物识别登录

明确排除，防止范围蔓延。
