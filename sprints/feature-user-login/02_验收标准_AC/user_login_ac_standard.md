# 用户登录 验收标准 (AC)

> 迭代：feature-user-login
> 用途：PM / QA / 开发共同确认「做到什么程度算完成」

---

| 编号 | 验收项 |
| --- | --- |
| AC1 | 正确账号密码可以登录，刷新页面登录态保留（勾选「记住我」） |
| AC2 | 密码错误返回友好提示；**不会**提示「账号是否存在」（安全原则：不泄露账号是否注册） |
| AC3 | 连续 5 次错误登录后账号锁定 15 分钟，期间登录被拒绝并有提示 |
| AC4 | 点「退出登录」，登录态清除；再访问需要登录的页面会被重定向回登录页 |
| AC5 | 未登录直接在地址栏输入受保护页面 URL，自动跳转到登录页；登录成功后回到刚才想去的页面 |
| AC6 | 网络异常、接口 500 时页面给出「网络异常，请稍后重试」，不会卡死 |

---

## 补充验收
- 登录 loading 期间按钮 disable，防止重复点击
- 登录失败仅清空密码输入框，账号保留
- 移动端 & PC 端表单均可正常操作
- HTTPS 强制生效，HTTP 自动 301
