# 用户登录 测试用例 / 自测清单

> 迭代：feature-user-login
> 用途：QA 测试执行清单，开发提测前自测清单

---

## 一、功能
- [ ] 正确账号密码登录成功，登录态保存
- [ ] 退出登录成功，鉴权失效
- [ ] 勾选「记住我」→ 7 天内免登录
- [ ] 不勾选「记住我」→ 关闭浏览器后登录态失效（或按业务规则）

## 二、边界 & 异常输入
- [ ] 账号为空 → 前端提示必填
- [ ] 密码为空 → 前端提示必填
- [ ] 账号超长（35 位以上）→ 前端拦截或服务端拒绝
- [ ] 密码超长（35 位以上）→ 前端拦截或服务端拒绝
- [ ] 密码 < 6 位 → 前端提示格式错误
- [ ] 特殊字符 / SQL 注入字符输入 → 服务端安全拦截
- [ ] 密码连续 5 次错误触发锁定
- [ ] 锁定后第 6 次尝试直接拒绝并提示锁定
- [ ] 15 分钟后账号自动解锁

## 三、安全
- [ ] 多次错误登录**不能**告知「账号不存在」，统一「账号或密码不正确」
- [ ] 密码在网络传输必须走 HTTPS，禁止明文
- [ ] 前端 localStorage / cookie 存储凭证符合安全属性（HttpOnly 优先）
- [ ] 退出后旧的 token / session 失效，不能继续调用鉴权接口
- [ ] 抓包检查密码不出现在明文日志中
- [ ] XSS 注入尝试（账号/密码字段）被过滤

## 四、鉴权拦截
- [ ] 未登录直接访问受保护页面 URL → 跳转登录页
- [ ] 登录成功后自动跳回来源页
- [ ] 已登录用户访问登录页的行为符合约定
- [ ] 接口 401 → 前端自动跳登录页

## 五、兼容
- [ ] PC 端（Chrome / Safari / Edge / Firefox）登录表单正常显示与操作
- [ ] 移动端（iOS Safari / Android Chrome）登录表单正常显示与操作
- [ ] 输入框、按钮、复选框可正常点击

## 六、异常场景
- [ ] 网络断开 → 提示「网络异常，请稍后重试」
- [ ] 服务端返回 500 → 提示友好文案，不卡死
- [ ] 服务端返回 504 超时 → 有 loading 结束逻辑
